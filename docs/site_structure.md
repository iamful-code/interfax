# Что известно о структуре e-disclosure.ru (и что не проверено)

Живого доступа к сайту при разработке не было (сетевая политика окружения; кроме того, сайт отдаёт
**403 при запросах не с российских IP** — по опыту открытых проектов). Ниже — сводка из открытых
источников и предположения, которые нужно подтвердить командой `disclosure-alpha discover`.

## Подтверждено открытыми источниками
| Элемент | URL / разметка | Источник |
|---|---|---|
| Страница компании | `https://e-disclosure.ru/portal/company.aspx?id=<int>` (на странице ИНН, ОГРН) | ссылки в поиске, e-disclosure |
| Страница сообщения | `https://e-disclosure.ru/portal/event.aspx?EventId=<строка вида pHCdwvYkFkau-A8zAGePZqg-B-B>` | ссылки в поиске |
| Файлы отчётности компании | `https://www.e-disclosure.ru/portal/files.aspx?id=<company_id>&type=<3 РСБУ / 4 МСФО>` | проект feeleen/EDisclosureMonitor |
| Лента последних сообщений | `https://www.e-disclosure.ru/portal/lastnews.aspx`, блоки `div.lastNewsItem` с `a[href*=EventId]`, временем `ДД.ММ.ГГГГ ЧЧ:ММ` и `div.lastNewsItemInfo` («эмитент, тип события») | проект maxopetya/baryga |
| Поиск по сообщениям | `https://e-disclosure.ru/poisk-po-soobshheniyam` (фильтры: компания/ИНН/ОГРН, тип сообщения, регион, отрасль, даты) | сайт |
| Гео-блокировка | 403 не с российских IP | README baryga |
| Ограничение частоты | при частых запросах сервер временно блокирует | README EDisclosureMonitor |
| Платный REST API | подключается через Личный кабинет → Услуги; для нашей задачи не требуется | e-disclosure |

## Предположения (проверить через discover)
* Имена полей формы поиска: `dateStart`, `dateFinish`, `lastPageNumber`, `lastPageSize`,
  `eventTypeCheckboxGroup` (чекбоксы типов), `query`/`queryId`, `eventTypeTerm`, `radView`.
  Переопределяются в `config/edisclosure_form.json` → `{"field_map": {"date_from": "...", ...}}`.
* Форма отправляется POST на тот же адрес; результаты — таблица со строками «дата | компания | сообщение».
  Парсер не зависит от вёрстки: берёт ближайший `tr`/`li`/`div` вокруг ссылки на событие.
* Максимальный размер страницы — вероятно 100 (`lastPageSize`); если сайт игнорирует номер страницы,
  клиент останавливается по повтору идентификаторов.
* Список типов сообщений (идентификаторы чекбоксов) — извлекается из формы (`event_type_options()`),
  затем сопоставляется с категориями `config/event_types.yaml` по регулярным выражениям.
* Поиск компании по ИНН — страница `poisk-po-kompaniyam` (структура не проверена); запасной путь —
  поиск по сообщениям с `query=<ИНН>` и чтение `company.aspx?id=` из результатов.

## Что делает `discover`
Скачивает страницу поиска, ленту, одно событие и одну компанию; сохраняет HTML в `data/discovery/`,
а в `discovery.json` — найденные формы (все поля, чекбоксы с подписями), ссылки `/portal/...` и
URL-подобные строки из скриптов (ajax-эндпоинты). По этому файлу за пару минут подтверждаются или
правятся имена полей — без изменения кода.
